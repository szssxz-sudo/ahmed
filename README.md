# Telegram Trading Bot & Webhook

بوت تليجرام مخصص لاستقبال تنبيهات التداول (Webhooks) من منصة TradingView وتنفيذها وإرسالها فوراً إلى المحادثة.

## 🚀 المميزات
* استقبال طلبات POST عبر مسار الويب هوك `/webhook`.
* إرسال التنبيهات وتنسيقها بشكل آلي إلى تطبيق تيليجرام.
* مبني باستخدام لغة Python وإطار عمل Flask.
